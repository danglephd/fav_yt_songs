# Fav YouTube Songs

Ứng dụng Angular để lưu, tìm kiếm, lọc và phát danh sách video YouTube. Giao diện đang được dùng tại route `/`; route `/my-songs-2` hiện vẫn trỏ tới giao diện My Songs cũ.

## Bắt đầu

- Cài dependencies bằng `npm install` hoặc `yarn install`.
- Cấu hình Firebase và YouTube API trong `src/environments/environment.ts`.
- Chạy `npm start` để mở ứng dụng bằng Angular development server.
- Xem [AI_SETUP_GUIDE.md](AI_SETUP_GUIDE.md) để biết ranh giới source và cấu hình môi trường.
